# CMZ Fitness — Landing Page Final

Projeto institucional em Next.js com a identidade final da CMZ Fitness.

## Iniciar no Windows

Dê dois cliques em `INICIAR-SITE.bat`. O script limpa o cache antigo, instala as dependências caso estejam faltando e abre `http://localhost:3000`.

## Visualização imediata

Abra `preview-estatico/index.html` para visualizar a landing sem instalar pacotes.

## Logo aplicada

A versão amarela e branca foi aplicada no cabeçalho e no rodapé:

`public/brand/cmz-logo-white-yellow.png`

## Arquivos principais

- `app/page.tsx`: textos, links e estrutura
- `app/globals.css`: identidade visual e responsividade
- `public/images/hero-gym.webp`: hero
- `public/images/cassio-muniz.webp`: retrato do CEO
- `public/icon.png`: favicon

## Recuperação

Caso um editor gere erro de cache ou Webpack, feche o servidor e execute `REINSTALAR-PACOTES.bat`.
